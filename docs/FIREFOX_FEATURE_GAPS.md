# Firefox 功能对照与实现状态

参考对象：本机安装的 **Firefox 159.0.1（x64 中文版）**。

本轮已按「全做」目标落地一组接近 Firefox 的浏览器能力，并把设置页重排为 Firefox 式左侧分类导航、顶部设置搜索、右侧卡片内容。

## 已落地

### 标签页与窗口
- 固定标签页
- 标签组：新建、重命名、颜色、分配标签、删除
- 标签搜索（`Ctrl + Shift + A`）、标签预览提示
- 关闭重复标签页
- 关闭多个标签页时确认

### 书签
- 书签文件夹
- 地址栏下方收藏夹栏
- HTML 书签导入/导出
- 批量选择、移动、删除
- 收藏星标位于地址栏右侧

### 阅读与采集
- 阅读模式
- 整页截图和拖动区域截图
- 内置 PDF 阅读器
- 当前页面另存为 PDF
- 打印页面

### 下载
- 暂停/继续
- 下载前询问保存位置
- 下载目录自定义
- 下载完成后打开
- 按扩展名自动打开
- 无痕下载记录清理

### 隐私与安全
- 标准 / 严格跟踪保护
- Cookie 横幅自动隐藏
- 退出时清理缓存、Cookie 或全部数据
- 站点权限例外（摄像头、麦克风、定位、通知、剪贴板）
- HTTPS-Only、DoH、系统/直连/手动代理
- DNT / GPC

### 搜索
- 自定义搜索引擎
- 关键字快捷搜索（例如 `gh electron`）
- 地址栏本地建议与远程搜索建议

### 密码与数据
- 本机加密密码库（Electron safeStorage）
- 密码生成器
- CSV 导入
- 一键填充当前页登录表单
- 密码泄露检查
- 本地备份/恢复：书签、书签文件夹、历史、设置、标签组

### 扩展与主题
- 内置广告与跟踪拦截
- 本地扩展安装（`plugin.json` + `content.js`，支持域名拦截）
- 明月 / 经典界面风格、浅色 / 深色 / 跟随系统、字体大小、强调色

### 媒体、系统与辅助
- 画中画
- 自动播放策略
- 开机启动
- 默认浏览器入口
- 高对比度、减少动画
- 明月自绘标题栏与窗口控制按钮

### 语言与翻译
- 浏览器界面语言默认跟随系统，可手动选择简体中文、繁體中文、English、日本語
- 网页机翻目标语言可独立选择四种语言
- 本机语言字典覆盖设置页、工具栏、起始页、书签/历史/下载/插件页与常用提示

## 平台/产品边界

下面这些不是单个前端开关能完成的，当前发布版保持诚实状态：

- **账户与跨设备同步**：按需求先做占位页，提示后续版本更新；当前只提供本地备份/恢复。
- **在线插件/主题商店**：需要独立的商店服务和审核机制；当前提供本地扩展安装，已有内置广告拦截插件。
- **DRM 受保护媒体**：需要 Widevine 等授权 CDM，无法在纯开源源码中合法内置。
- **PDF 标注**：当前集成 Chromium PDF 阅读器；绘制标注需要额外的 PDF.js 标注层。
- **自动更新**：需要发布服务器、签名和更新通道；当前「系统与更新」提供状态说明。
- **发布形式**：当前提供源码、Windows x64 便携版 exe 与 Android APK；未签名，首次运行可能触发 SmartScreen 提示。
